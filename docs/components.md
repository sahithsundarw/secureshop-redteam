# Vulnerable components in the lab build

The deliberately vulnerable Flask app (local, 127.0.0.1, authorised university lab) pins three outdated components. This file records the pinned versions, the latest stable versions, and published advisories that apply to the exact pinned versions. Every id below was read on the cited page; nothing is from memory.

## Also fetched but not applicable or not primary

- CVE-2023-23934 / GHSA-px8h-6qxv-m22q (Werkzeug nameless cookies): affects < 2.2.3, so 2.0.3 is affected. Low severity (CVSS 2.6), needs an adjacent subdomain. Omitted from the table to stay within three per component. Source: https://github.com/advisories/GHSA-px8h-6qxv-m22q
- CVE-2024-49766 / GHSA-f9vj-2wh5-fj8j (Werkzeug `safe_join` UNC path): page states "3.0.5 and earlier"; only affects Windows with Python < 3.11. The lower bound was not stated on the fetched page, so applicability to 2.0.3 is **unverified**. Not used. Source: https://github.com/advisories/GHSA-f9vj-2wh5-fj8j
- CVE-2019-11358 / GHSA-6c3j-c64m-qhgq (jQuery `extend` prototype pollution): npm range >= 1.1.4, < 3.4.0, so 1.12.4 is affected, fixed in 3.4.0. Omitted from the table (limit of three). Source: https://github.com/advisories/GHSA-6c3j-c64m-qhgq
- Newer Werkzeug ids seen only in the PyPI vulnerability list for 2.0.3 (CVE-2023-46136, CVE-2025-66221, CVE-2026-21860, CVE-2026-27199, CVE-2026-102598): unverified, because their GitHub advisory pages were not fetched. Not relied on.

## How verified

Checked on 2026-10-08. Affected ranges and fixed versions come from GitHub Advisory Database pages (github.com/advisories/GHSA-...) fetched with WebFetch. Latest Flask and Werkzeug versions come from the PyPI JSON API and project page; the Flask and Werkzeug 2.0.3 PyPI JSON pages also listed these ids. Latest jQuery comes from https://jquery.com/download/ (4.0.0) and https://github.com/jquery/jquery/releases (3.7.1, 4.0.0). NVD pages returned no content through the fetch tool, so NVD was not used as a source. The Flask 2.0.3 lower bounds are implied by "before X" wording; no lower bound was stated for CVE-2026-27205.
